# 🧁 Mrs. Cupcake — Special Birthday Tribute to Mrittica Didi ✨

A handcrafted, interactive web experience built with boundless love by **Arnab** to celebrate **Mrittica Naskar (Mrs. Cupcake)** turning 24!

## 🌟 Highlights & Features

- 🎵 **Soundtrack**: Features *"Fakira"* by Sanam Puri & Neeti Mohan with a floating vinyl player, lyrics popup, and animated equalizer.
- 🎠 **Cinematic Photo Memory Slider**: Full-width interactive reel showcasing real memories with swipe/touch gestures, auto-play, and dot navigation.
- 💖 **24 Reasons Why Didi is Unmatched**: An interactive 24-card carousel celebrating 24 wonderful qualities of Didi with a surprise randomizer.
- 🎮 **4-Game Arcade Hub**:
  1. **Cupcake Rush**: Arcade canvas catcher game with mobile touch controls.
  2. **Festive Handi Burst**: Traditional Bengali Matka crack game with health durability, whack stick, sound FX, vibration, and confetti revealing Didi's Royal Decree.
  3. **Sweet Memory Match**: 4×3 3D card flip memory matching game with timer and move tracker.
  4. **24th Birthday Cake Studio**: Custom 3-tier cake decorator (flavors & toppings) with interactive candle blowout animation and fanfare.
- 🗣️ **Sibling Soundboard**: 6 interactive sound chips featuring Didi's famous catchphrases.
- 📌 **Dynamic Wishes Wall**: Sticky blessing notes with a live submission form to pin new wishes.
- 📱 **Mobile & Touch Optimized**: Designed for iOS Safari and Android Chrome with safe-area notch support and full responsive styling.

## 🚀 Running Locally

To run the local development server:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
